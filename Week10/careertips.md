Roles

- DevOps Engineer → builds & automates delivery pipelines
- SRE (Site Reliability Engineer) → keeps systems reliable in production
- Platform Engineer → builds internal platforms/tools for developers

DevOps = delivery
SRE = reliability
Platform = developer experience at scale


1️⃣ DevOps Engineer

Focus

Shipping code faster and safely

🛠 What they do
CI/CD pipelines (GitHub Actions, Azure DevOps)
Infrastructure as Code (Terraform — your current skill 👍)
Environment setup (dev/test/prod)
Automation
🔑 Skills needed
Terraform
Git & CI/CD
Cloud (Azure/AWS)
Docker basics

SRE (Site Reliability Engineer)
Focus

System reliability, uptime, and performance

Define SLI / SLO / SLA
Monitoring & alerting
Incident response (production issues)
Capacity planning
Postmortems

🔑 Skills needed
Kubernetes (strong)
Observability (Prometheus, Grafana, Azure Monitor)
Debugging (Linux, networking)
Automation (Python, Bash)


Example work
“Why did the system go down at 2 AM?”
“Reduce error rate from 2% → 0.1%”

Platform Engineer
🎯 Focus

Build internal platforms so developers don’t deal with infra

🛠 What they do
Build internal developer platforms (IDP)
Create reusable Terraform modules
Standardize deployments
Provide self-service tools
🔑 Skills needed
Kubernetes (very strong)
Terraform (advanced modules)
APIs & tooling
Developer experience mindset
📌 Example work
“Give developers a one-click way to deploy apps on AKS”

| Area      | DevOps          | SRE                    | Platform Engineering   |
| --------- | --------------- | ---------------------- | ---------------------- |
| Goal      | Faster delivery | Reliability & uptime   | Developer productivity |
| Focus     | CI/CD           | Monitoring & incidents | Internal platforms     |
| K8s usage | Deploy apps     | Debug & optimize       | Build platform on top  |
| Terraform | Use it          | Use + automate         | Build reusable modules |
| Mindset   | Automation      | Reliability            | Abstraction            |


If someone likes automation → DevOps
CI/CD pipelines
Infra setup
If someone likes debugging & systems → SRE
Monitoring
Incident handling
If someone likes architecture → Platform Engineer
Build internal tools
Design systems


👉 “DevOps Engineer” job often includes:

Terraform + Kubernetes + Monitoring

CI/CD + infra + reliability
